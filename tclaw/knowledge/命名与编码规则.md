# 命名与编码规则（新规范 · 2026-06-22 重订）

> 旧版 `产品线-产品系列-区域-物料类型-语言-年份-月日-版本号` 因过于复杂已弃用。现行规范按物料**三大类**分别命名，更简洁。

## 核心原则
- 按物料**三大类**（产品 / 品牌 / 展会）分别套用命名结构。
- **不含年月日**（仅展会保留开头 `(年份)`）；任何更新只升**版本号**，名字里不放日期。
- **区域用括号 `(市场码)` 且可省略**：Global / 总部 / 无指定区域 → 不显示（默认即 Global）；一份物料适用多区域时只显示一个（主区域）。
- 物料类型用**英文词**；语言用 **PascalCase**；产品型号**照搬真实串**。

## 三大类命名结构

### 1. 产品物料
```
产品型号-物料类型-语言-(区域)-版本号
```
- 例：`IPV-1K612U-Datasheet-En-(PK)-V1.0`
- Global 省区域：`IPV-1K612U-Datasheet-En-V1.0`

### 2. 品牌物料
- **LOGO（带品牌）**：`<品牌>-Logo-[语言]-[(区域)]-版本号` —— 例 `itel-Logo-V1.0`（logo 多为中性，语言/区域按需，可省）
- **其他**（画册/折页/datasheet 等，**不带品牌**）：`物料类型-语言-(区域)-版本号` —— 例 `Brochure-En-(PK)-V1.0`

### 3. 展会物料
```
(年份)展会名缩写-物料类型-(区域)-版本号        （无语言段）
```
- 例：`(2026)GITEX-Poster-(PK)-V1.0`、`(2026)MWC-Brochure-V1.0`

## 各段取值

### 产品型号（照搬真实串）
- 直接用产品团队的真实型号串，**含其中连字符原样进名字**（如 `IPV-1K612U`、`IHY-8K48`），不再解码/缩写。
- 产品线（AIO/INV/BAT/PPS/ESS…）**仅作多维表格分类字段，不进名字**。
- 型号含义仅在需要识别/匹配产品时参考 [产品型号解码.md](产品型号解码.md)。

### 物料类型（多维表格选项已是「英文token 中文」，命名直接取**英文 token**）
多维表格「物料类型」选项 = 真实产品资料包类型，格式 `英文token 中文`；命名段直接用**选项开头的英文 token**：

| 多维表格选项 | 命名 token | 说明 |
|---|---|---|
| Folder 折页 | Folder | 产品折页 |
| Flyer 单页 | Flyer | 单页 |
| Datasheet 数据表 | Datasheet | 数据表/规格书 |
| DetailPage 详情页/长图 | DetailPage | 产品详情页/介绍长图 |
| KV 主视觉 | KV | Key Visual 主视觉 |
| Manual 说明书 | Manual | 产品说明书 |
| USP 卖点文档 | USP | 产品卖点文档 |
| ProductVideo 产品视频 | ProductVideo | 产品视频 |
| InstallVideo 安装视频 | InstallVideo | 安装指导视频 |
| Photo 产品图/场景图 | Photo | 产品拍摄图/场景图 |
| IDImage ID白底图 | IDImage | ID 白底图 |
| Packaging 包装设计 | Packaging | 包装设计 |
| Social 社媒/一图读懂 | Social | 社媒设计/一图读懂 |
| Brochure 画册 | Brochure | 品牌/产品画册（多页册子）|
| Logo 品牌Logo | Logo | 品牌 Logo |
| VI 品牌视觉 | VI | 品牌视觉 VI |
| Poster 海报 | Poster | 海报 |
| PPT 演示 | PPT | 演示文稿 |
| Training 培训 | Training | 培训资料 |

> **产品标准资料包**通常含 Folder/Flyer/Datasheet/DetailPage/KV/Manual/USP/ProductVideo/InstallVideo/Photo/IDImage/Packaging/Social 多种类型，**每种是一条独立物料记录**（同一产品型号、不同物料类型）。

### 语言（PascalCase）
`En` 英 / `Cn` 中 / `Fr` 法 / `Ar` 阿 / `Es` 西。**展会物料无语言段。**

### 区域（括号 · 市场码 · 可省）
- 真实市场码加括号：`(PK)` 巴基斯坦 / `(NG)` 尼日利亚 / `(UZ)` / `(KH2)` …（完整清单以**人员定义表**「区域标识」为准，可扩展）。
- **Global / 总部(HQ) / 无指定区域 → 整段省略**（默认 Global）。
- 适用多区域时名字里**只显示一个（主区域）**；多区域可见性靠主表「适用区域」多选字段，不进名字。

### 版本号
- `V主.次`（V1.0 / V1.1 / V2.0）。
- **唯一的更新载体**：文案/图片/参数/结构任何更新都升版本号。升级规则见 [版本升级规则.md](版本升级规则.md)。

## 物料名称（可读名 · 与标准命名并存）
- 主表「**物料名称**」(主字段) = 中文可读名，让人一眼看出"这是什么物料"，如 `IPV-1K612U 数据表·巴基斯坦`、`itel 品牌画册`、`2026 GITEX 海报`。
- **标准命名**是文件/检索用的规范串，**物料名称**是给人看的，两者并存于主表。

## 变体后缀（色彩配置等 · 可选 · 少用）
有的物料**外观一样、只是某个非视觉属性不同**（最典型：Logo 的色彩配置 RGB vs CMYK，预览看不出区别）。这种情况**不另建记录**：
- **同一物料一条主记录**：多个色彩变体作为**多个附件**挂在同一条记录上（当前有效附件 / 源文件(L) 各放对应变体文件）。
- **用文件名区分**：在版本号前加可选变体段 `-<RGB|CMYK|…>` → 文件名 `<基名>-<变体>-版本号-<L|M|S>.ext`。
  - 例 一条 itel Logo 记录挂两份导出：`itel-Logo-RGB-V2.0-M.png`、`itel-Logo-CMYK-V2.0-M.png`（源文件同理 `-L`）。
- **主记录**：标准命名用不带变体的基名 `itel-Logo-V2.0`；物料名称标注含哪些变体，如 `itel 品牌 Logo（RGB+CMYK）`。
- 仅用于"看着一样、需区分"的场景；绝大多数物料用不到，**别滥加变体段**。

## 附件文件名（L/M/S 形态不变 · 不是主表字段）
> 主表只保留 **「标准命名」一个标准名列**（冗余的「标准文件名」字段已删除）。下面说的"标准文件名"只是**附件文件自身的命名规范**，用于上传前给文件改名，**不单独占主表字段**。
- **附件标准文件名 = 标准命名 + `-L|M|S` + 扩展名**。
  - L 源文件（PSD/AI·AI 不读）、M 导出件（PDF/PNG/JPG/MP4·AI 据此识别）、S 轻量预览。
  - 例 `IPV-1K612U-Datasheet-En-(PK)-V1.0-M.pdf`
- **上传任何附件(M/L/S)前，先把本地文件改名为标准文件名再 `record-upload-attachment`**，确保下载下来就是标准名。
- **关键**：入库时附件由自动化 08 从处理池**原样同步**到主表，所以文件名必须在**处理池阶段**就改对，否则同步到主表就是错名。

## 区域二创
- 区域本地化版本：在区域版本基础上加 `-R<n>`，例 `IPV-1K612U-Datasheet-En-(PK)-V1.0-R1`。
- 若总部原版为 Global（无区域段），二创版**补上该区域括号再加 `-R<n>`**：`IPV-1K612U-Datasheet-En-(PK)-V1.0-R1`。

## 唯一性
- 物料唯一性以主表「内部物料ID」(自动编号 `MAT-####`) 为准；可读命名允许偶发重复。
- 标准命名同前缀冲突时尾部加两位序号 `-NN`（仅冲突时出现）；生成前先 `record-search` 主表查重。

## 命名生成步骤
1. **先判物料大类**：产品物料 / 品牌物料 / 展会物料。
2. 基于**导出件 M** + 表单字段识别各段：
   - 产品物料：产品型号(照搬)、物料类型(→英文)、语言、区域(市场码或省)、版本号。
   - 品牌物料：是否 LOGO（是→`<品牌>-Logo-…`；否→`物料类型-语言-(区域)-版本号`）。
   - 展会物料：年份、展会名缩写、物料类型、区域、版本号（**无语言**）。
3. 缺关键项 → 走追问（只问必要的、问一次）。
4. 拼接标准命名 → 主表查重 → 冲突加 `-NN`。
5. 物料名称写完整中文可读名；为每个文件形态生成标准文件名并据此改名上传。
