# 产品型号解码规则

> **命名变更后定位**：新命名**照搬真实产品型号串**（如 `IPV-1K612U`）进名字，**不再用本规则构名**。本文件降级为**识别/匹配辅助**——帮你看懂某型号是什么产品（判断产品线分类、找旧版匹配、与产品负责人核对参数），不参与拼名字。
>
> 用于从型号推断产品类型/功率/电压/容量/相数。**未明确说明的后缀标注「未知后缀」，不要臆测。**

## 前缀与品类
| 片段 | 含义 |
|---|---|
| I（前缀） | 品牌/系列前缀 |
| PV | 离网逆变器 |
| HY | 混合逆变器 |
| GT | 并网逆变器 |
| ESS | 储能系统 |
| PL | 落地式电池 |
| PW | 壁挂式电池 |

## 逆变器型号
- 功率：`8K`/`12K`/`3.6` = AC 输出功率（8kW / 12kW / 3.6kW）。
- 电压平台：`48`/`24`/`12` = 51.2V / 25.6V / 12V。
- 相数：`L3` 或 `H3` = 三相。
- `T` = 并网或自研后缀。

## 电池型号
- 电压：`51`/`24`/`12` = 51.2V / 25.6V / 12V。
- 容量：后续数字 = 容量 Ah，如 `628` = 628Ah。

## 示例
- `IHY-8K48`：I 品牌前缀 + HY 混合逆变器 + 8K=8kW + 48=51.2V 平台 → 8kW 混合逆变器（51.2V）。

## 用法
识别物料对应产品时：拆解型号 → 推断**产品线分类字段**（不进名字）与产品系列、用于找旧版匹配；命名时**产品型号段照搬真实型号串**。无法确定的段标「未知后缀」并在缺失信息中追问产品负责人。产品的上市/认证状态、标准卖点、禁用表达若需校验，向产品负责人确认（产品基础信息后续可维护为独立产品库表）。
