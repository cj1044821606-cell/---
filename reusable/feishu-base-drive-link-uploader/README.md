# 飞书多维表格附件 → 云盘链接回填器

## 全文摘要

这个小工具会把一条多维表格记录中的附件下载到临时工作目录，上传到指定飞书云盘文件夹，设置链接可见范围，再把云盘链接写回同一条记录的文本字段。它适合解决工作流直接发送大附件失败的问题：发送工作流改为读取链接字段即可。工具支持 M/L/S 等多个附件字段、一个字段多个附件、按文件大小打标、单条运行和扫描补漏；重复运行不会覆盖已有链接。

**预估阅读时间：5 分钟。**

## 适用场景

- 用户从多维表格附件字段上传文件，后续需向员工发送下载链接。
- 工作流有附件大小限制，想让小文件仍发附件、大文件改发云盘链接。
- 希望每条已经定稿的主表记录，都有可追溯的云盘备份链接。

> 推荐把它运行在“文件已确认/已入库”的表或状态之后。这样云盘文件会沿用最终标准文件名，避免上传原始文件后还要二次改名。

## 目录与文件

| 文件 | 用途 |
|---|---|
| `feishu_base_drive_uploader.py` | 核心脚本：下载、上传、设权限、回填、扫描补漏。 |
| `drive_upload.env.example` | 配置模板；复制成 `drive_upload.env` 后填写。 |
| `README.md` | 本说明。 |

本通用包**不包含事件监听器**。事件监听可能和机器人收消息共用同一条飞书事件连接，容易冲突；建议用定时任务、cron 或现有 Agent 的轮询流程定期执行 `--sweep`，更稳。

## 工作方式

```text
定时任务 / Agent 轮询
        ↓
--sweep 找到“附件存在、云盘链接为空”的记录
        ↓
下载 Base 附件 → 上传指定云盘文件夹 → 设链接权限
        ↓
回填 云盘链接M / L / S（可选：打 是否大文件）
        ↓
领取或通知工作流按链接字段发送
```

## 安装与配置

1. 把整个目录复制到要运行的 Linux VM 或电脑。该机器必须已经配置好 `lark-cli` 的 `user` 身份，并能访问目标 Base 与云盘文件夹。
2. 在脚本目录中复制配置模板：

```bash
cp drive_upload.env.example drive_upload.env
```

3. 用目标多维表格的 `field-list` 结果填写 `drive_upload.env`。最关键的不是字段显示名，而是附件字段的 `field_id`。链接字段可以填显示名，例如 `云盘链接M`。
4. 创建一个专用云盘文件夹，把它的 folder token 填入 `DRIVE_FOLDER_TOKEN`。
5. 先校验配置（不会上传文件、不会写表）：

```bash
python3 feishu_base_drive_uploader.py --validate
```

6. 选一条测试记录运行：

```bash
python3 feishu_base_drive_uploader.py rec_xxx
```

成功后，回到多维表格确认对应的 `云盘链接…` 字段已填入链接，并换一个组织内账号打开链接验证权限。

## 日常触发方式

最稳的做法是每 1–5 分钟运行一次扫描补漏：

```bash
python3 feishu_base_drive_uploader.py --sweep
```

它只处理“sweep 指定附件字段有文件、但对应云盘链接仍为空”的记录。因此即使机器重启、某次任务失败或历史记录漏传，下次扫描仍会补上；已有链接的记录会自动跳过。

## 大文件混合发送

如果你的领取工作流会一次发送 M/L/S 多个附件，建议设：

- `BIG_FILE_FIELD="是否大文件"`
- `BIGCHECK_FIELD_IDS` 填 M/L/S 三个附件字段 ID；
- `BIG_FILE_MB="28"`，为 30MB 工作流上限留安全余量。

脚本会在三个附件字段中任一文件达到阈值时勾选复选框。工作流据此分支：未勾选就发送原附件，勾选就发送三个云盘链接。

## 必须遵守的维护规则

- **链接为空才上传。** 这是幂等保护，避免轮询重复把同一附件传很多次。
- **原地替换附件时，先清空该记录的云盘链接字段和大文件标记。** 下次 `--sweep` 才会上传新文件并回填新链接；否则会留下指向旧文件的链接。
- **版本替换新建记录时不需要特殊处理。** 新记录的链接本来为空，扫描会自动上传新版。
- **不要用事件监听器来触发此包。** 用轮询/定时任务即可，避免影响机器人正常接收飞书消息。

## 常见问题

| 现象 | 排查 |
|---|---|
| `配置字段不存在` | 对目标表跑 `field-list`，核对附件 field_id 与链接字段显示名。 |
| 链接没有回填 | 看 `.drive_upload_work/uploader.log`；确认 `UPLOAD_IDENTITY` 对 Base 有编辑权。 |
| 云盘上传失败 | 确认 `DRIVE_FOLDER_TOKEN`、用户身份对目标云盘文件夹有写权限。 |
| 云盘链接外部人员打不开 | 当前默认是 `tenant_readable`，只限组织内；如需外发，必须先按公司安全政策单独调整权限策略。 |
| VM 报路径不安全 | 不要把 `WORK_DIR` 设为绝对路径；本包已强制把临时文件放到脚本目录内。 |
